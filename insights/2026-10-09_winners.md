## 2. Why the System Missed Them

### 2.1 The `composite=nan` Problem (Critical Failure)

9/10 winners have `composite=nan`. This is the primary failure. Likely causes:

- **Missing `weekly_vol`**: All 10 winners show `weekly_vol=n/a`. If `weekly_vol` is a required input to the composite score calculation and it is null, the entire composite collapses to NaN via propagation.
- **Action required**: Audit the composite scoring function for NaN propagation. Apply `fillna` or imputation for `weekly_vol` before composite calculation. CEFs and income funds frequently lack this field.

### 2.2 Negative `ev_score` Systematically Penalizes CEFs

All winners have `ev_score` ranging from -0.023 to 0.000. Enterprise value metrics (EV/EBITDA, EV/Sales) are **conceptually inapplicable** to closed-end funds, where "enterprise value" reflects NAV discount/premium dynamics, not operational leverage. If `ev_score` enters the composite with non-trivial weight and is consistently negative for CEFs, the system structurally undervalues this entire asset class.

### 2.3 Clone Ranking — NEA, NMZ, PDI, GAB All Rank Identically

These four stocks share **identical signal vectors to 3 decimal places** and all receive `alpha_rank=368`. This suggests the ranking pipeline is treating them as a group or there is a data deduplication issue. Real differentiation within the group (e.g., NMZ returned +2.1%, GAB returned -0.6%) is not being captured by any signal — but they shouldn't all receive the exact same rank. This is a data pipeline or signal computation bug.

### 2.4 `trend=0.000` in High-Vol-Surge Winners

NAD (+3.0%), NZF (+1.8%), JPC (+0.6%) all have `trend=0.000` but `vol_surge` of 0.892, 0.726, and 0.830 respectively. The system is likely underweighting `vol_surge` relative to `trend` in the composite. In a **trending_mixed** regime where trending momentum is ambiguous, volume surge breakouts from low-trend bases are a classic mean-reversion/breakout setup that the system is not capturing.
